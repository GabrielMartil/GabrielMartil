### 🙋‍♂️ Sobre mim

Sou desenvolvedor full stack em Fortaleza. Gosto de construir sistemas completos, do banco de dados à interface, e de ver o que eu faço sendo usado de verdade no dia a dia das pessoas.

Trabalho com web, desktop e mobile. Já desenvolvi plataformas para empresas, integrações com hardware, apps próprios, sistemas para a área da saúde e até jogos.

Comecei a programar com Python e hoje uso principalmente **Go** e **TypeScript**. Nas horas livres, tiro ideias do papel em projetos pessoais. 🚀

### 💼 O que eu faço

- APIs e serviços em Go
- Aplicações web, desktop e mobile com React e React Native
- Integrações com ERPs e equipamentos, como impressoras, balanças e RFID
- Modelagem e otimização de bancos de dados
- Automação de processos
- Deploy com Docker e Jenkins, monitoramento com Grafana e Loki
